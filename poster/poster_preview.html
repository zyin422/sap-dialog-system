1. Introduction & Clinical Motivation

Motor speech disorders (dysarthria) affect over 100 million individuals globally resulting from Cerebral Palsy, ALS, Parkinson’s disease, and stroke. While voice interfaces offer vital accessibility for individuals with physical motor impairments, commercial systems fail drastically.

  • Acoustic Degradation: Dysarthric speech exhibits hypernasality, prolonged phonemes, atypical pitch contours, and variable speech rate. Commercial ASR models (Siri, Google, Alexa) yield Word Error Rates (WER) of 30%–50%+.
  • Turn-Taking Truncation: Involuntary mid-sentence pauses trigger standard Voice Activity Detection (VAD) energy cutoffs, prematurely terminating user commands.

2. The "Beyond WER" Problem

Speech benchmarks universally prioritize minimizing transcription WER. However, downstream task completion demonstrates starkly non-linear sensitivity to acoustic errors:

  • Benign Disfluencies: Dropped function words ("the", "a"), repetitions, and fillers ("uh", "um") are readily absorbed by downstream LLM contextual priors.
  • Catastrophic Entity Corruptions: Phonetic mutations in action slots and named entities (e.g., "call mom" → "call tom"; "5mg" → "50mg") trigger unrecoverable downstream failures or hazardous actions.
Research Question (RQ): What quantitative gains does dysarthria-specific acoustic adaptation yield at the level of downstream spoken language understanding (SLU) and tool invocation, beyond transcript WER?

3. Audited SLU Benchmark (Schema v1.3)

Evaluation audio is sourced from the Speech Accessibility Project (SAP) at UIUC Beckman Institute. To quantify downstream task execution, we formulated an audited SLU benchmark grounded in OpenAPI 3.0 tool schemas:

  • 1,274 Canonical Gold Commands: Multi-model consensus (Claude 3.5 Sonnet & GPT-4o) adjudicated with human verification. 100% compliant with strict typing, explicit enum constraints, and slot validation rules.
  • 35 Out-of-Domain (OOD) Items: Standalone wake phrases, OS system utility invocations, and dictation fragments partitioned out to prevent metric distortion.
  • 10 Real-World Domains (29 Tools): Health (`health_log`), Communication (`messages_send`, `calls_dial`), Calendar/Alarm (`alarm_create`), Smart Home, Media, Places, QA, Notes, Accessibility, and Transport.
  • Speaker-Disjoint Protocol: Evaluation audio is strictly disjoint from acoustic training splits to measure true generalized adaptation.

5. Controlled Evaluation Protocol

To strictly attribute downstream performance shifts, the downstream LLM agent prompt, OpenAPI tool definitions, and decoding temperature ($T=0.0$) are held 100% identical across three experimental conditions:

  • Condition 1 (Oracle Ceiling): Pristine human ground-truth transcripts provided to the agent. Quantifies the LLM's intrinsic semantic reasoning ceiling.
  • Condition 2 (Base ASR Baseline): Unadapted zero-shot NVIDIA Parakeet-TDT 0.6B (Acoustic WER: 28.15%).
  • Condition 3 (Fine-Tuned ASR): Parakeet-TDT fine-tuned on speaker-disjoint SAP dysarthric audio (Acoustic WER: 10.70%).

Metric Decompositions & Formulations:

  • Tool Selection (TS): Exact match of the target API function.
  • Parameter Filling (PF): Strict exact match of all ground-truth slot keys and argument values.
  • Command Frame Accuracy: Strict end-to-end task completion ($\text{TS} = 1 \land \text{PF} = 1$).
Core Analytical Metrics:
\[\text{ARR} = \frac{\text{Acc}_{\text{FT}} - \text{Acc}_{\text{Base}}}{\text{Acc}_{\text{Oracle}} - \text{Acc}_{\text{Base}}} \times 100\% \quad \Big( = \mathbf{71.44\%} \Big)\]
\[\text{SECR} = \frac{\text{Slots}_{\text{Repaired}}}{\text{Slots}_{\text{Eligible}}} \times 100\% \quad \Big( = \mathbf{35.07\%} \Big)\]

Strict Constant Control: All downstream prompts, OpenAPI tool parameter schemas, and decoding parameters are frozen at greedy $T=0.0$.

7. Error Analysis & Full-Duplex Roadmap

Prompt: "Set alarm for 7:30 am"

Execution: alarm_create(time="several:30") → Type Error (Crash)

FT ASR: "set alarm for 7:30 a.m."
Execution: alarm_create(time="07:30") → Task Success

Semantic Error Correction (SECR): In 35.07% of eligible corrupted slots, the LLM successfully inferred ground-truth arguments using phonetic and sentence context (e.g., "call doctor house agar" → "Dr. Hasegawa").

Immediate Research Roadmap:

  • Corpus Scaling: Scale inference across all 1,274 audited gold utterances on NCSA Delta GPUs.
  • Phonetic Tolerance: Incorporate Double Metaphone / Soundex distance metrics into parameter grading to avoid penalizing near-miss phonetic spellings.
  • Full-Duplex Turn-Taking: Develop pause-tolerant atypical VAD models to replace push-to-talk, preventing cutoff during prolonged phonations.
  • Edge Assistant: Quantize fine-tuned streaming ASR for on-device deployment in accessible hardware.
