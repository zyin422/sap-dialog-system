1. Introduction

  • Dysarthria pushes commercial ASR WER from 3.2% to 36.3%
  • One wrong phoneme changes the meaning: “call Kathy” → “call Cassie”, “turn on” → “turn off”, “5mg” → “50mg”.
  • Errors in ASR-sensitive slots may propagate to LLM tool execution
What does fine-tuning a streaming ASR on dysarthric speech buy us in a downstream assistant, measured by task completion instead of WER?

4. Metrics

Word Error Rate (WER)

Acoustic Baseline
Acoustic Token Distance: Levenshtein edit operations—Substitutions (S), Deletions (D), and Insertions (I)—over gold tokens (N).
Acoustic Blind Spot: Weights all token errors identically. Benign dysarthric hesitations or vocal tremors sharply inflate WER without impairing intent. Conversely, a single corrupted phoneme in a critical slot (“5mg” → “50mg”) has low WER penalty but fatal downstream impact.

Parameter Filling (PF)

Downstream SLU Metric
Semantic Parameter Grounding: Exact-match ratio of extracted slot values against canonical gold OpenAPI tool arguments.
The Primary Bottleneck: Intent routing is resilient (74.55%), but Base ASR degrades PF by 42.19% (88.41% → 46.22%). Fine-tuning recovers +29.51% PF, driving our 62.67% Adaptation Recovery Rate.
Command Frame Accuracy: End-to-end task completion requires both correct Tool Selection (TS = 1) and 100% Parameter Filling (PF = 1).
