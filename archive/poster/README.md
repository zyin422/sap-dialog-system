## How to View & Print the Poster (48" × 36")

### 1. View Direct PDF
Open [`Beyond_WER_Poster_48x36.pdf`](Beyond_WER_Poster_48x36.pdf) in Acrobat Reader, Preview, or Chrome.

### 2. Interactive Browser View
Open [`poster.html`](poster.html) in any modern browser:
```bash
open poster/poster.html
```
Press `Cmd + P` with paper size `48.0 x 36.0 in` (Landscape) and `Background graphics` checked to print.
